# Sandbox integration template

Adds a capture as an entry on a page in your tool, from one JavaScript file (`index.js`) that 1weavr runs for you.

Press **Use this template** to make your own repository.

**Docs:** the calls it answers, their inputs and outputs, and the security rules: https://1weavr.com/docs/integration-templates#sandbox
